02 / Sobre mim

Prazer,
João Mateus.

Sou João Mateus, desenvolvedor Full-Stack. Construo aplicações web completas: a interface que o cliente vê e a estrutura por trás, com banco de dados, autenticação e regras de negócio.

Gosto de projetos que resolvem um problema real. Já desenvolvi painéis financeiros, sistemas de gestão com vários perfis de acesso, plataformas voltadas à acessibilidade e sites com consumo de APIs. Cada projeto nasce de uma conversa para entender o que o seu negócio precisa.

Base

Front-end com atenção ao detalhe

HTML, CSS e JavaScript puro, depois React. Interfaces responsivas, rápidas e agradáveis de usar.

Evolução

Back-end e dados

APIs com Node.js e banco de dados com Supabase, incluindo autenticação e controle de acesso.

Hoje

Projetos completos, do início ao fim

Planejamento, design, desenvolvimento, publicação e suporte para sites, landing pages e sistemas web.
